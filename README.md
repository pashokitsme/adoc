# adoc

Неофициальный API-Wrapper для сайта [autodoc.ru](https://www.autodoc.ru) для получения информации об артикуле, цене,
наличии, сроке, отзывах, своём гараже и заказах.

```console
$ adoc part n90954802
ID   ПРОИЗВОДИТЕЛЬ  НАЗВАНИЕ  ОТ     СРОК     РЕЙТИНГ     НАЛИЧИЕ
657  VAG            Болт      317 ₽  сегодня  4.91★ (56)  4 шт
```

Autodoc не документирует свой API, а `adoc` — это неофициальный клиент. Вся полученная информация может быть неточной, неполной и устаревшей –
[docs/autodoc-api.md](docs/autodoc-api.md).

## Установка

```sh
$ bun install -g github:pashokitsme/adoc
$ gh skill install pashokitsme/adoc adoc
```

## Использование

| команда | что делает | авторизация |
|---|---|---|
| `search <текст>` | подсказка по названию: категории и производители | |
| `goods <categoryId>` | товары внутри категории | |
| `part <артикул>` | кто выпускает артикул, почём, рейтинг, наличие | |
| `info <артикул> [brandId]` | карточка: гистограмма оценок, наличие, категория | |
| `reviews <артикул> [brandId]` | отзывы и выжимка нейросети | |
| `prices <артикул> [brandId]` | предложения продавцов: цена, срок, количество | да |
| `analogs <артикул> [brandId]` | аналоги | да |
| `garage` | машины в гараже, ★ отмечает основную | да |
| `garage parts <carId>` | подборка запчастей под конкретную машину | да |
| `garage main <carId>` | сделать машину основной | да |
| `basket` | корзина | да |
| `favorites [listId]` | избранное; без аргумента — списки | да |
| `orders` | заказы | да |
| `profile` | сводка по аккаунту | да |
| `login` | авторизоваться | |
| `logout` | забыть токен | |
| `whoami` | кто авторизован и сколько живёт токен | |
| `get <путь> [k=v ...]` | GET к любому эндпоинту из карты API | `--auth` |
| `post <путь> [k=v ...]` | POST к любому эндпоинту из карты API | `--auth` |

| флаг | что делает |
|---|---|
| `--json` | сырой ответ вместо таблицы, для `jq` |
| `--limit <n>` | сколько строк показывать, по умолчанию 10 |
| `--page <n>` | страница выдачи |
| `--sort <id>` | порядок сортировки; доступные id печатает сама команда |
| `--auth` | слать токен в `get` и `post` |

`brandId` необязателен: если производитель один, он подставляется сам. Если их
несколько, `adoc` печатает список и выходит с кодом 2 — тогда id передаётся
вторым аргументом. Коды возврата: `0` — нашлось, `1` — ошибка или пусто,
`2` — нужен `brandId`.

## Авторизация

```sh
$ adoc login      # авторизация при помощи логина и пароля
$ adoc whoami    	# показывает текущего пользователя
$ adoc logout     # разлогинивает
```

Есть путь без пароля: в консоли браузера на сайте с открытой сессией —
`copy(JSON.stringify(sessionStorage))`, вставка — в `adoc login --paste`.
