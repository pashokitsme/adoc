# adoc

Автозапчасти с [autodoc.ru](https://www.autodoc.ru) из терминала: артикул, цена,
наличие, срок, отзывы, свой гараж и заказы.

```console
$ adoc part n90954802
ID   ПРОИЗВОДИТЕЛЬ  НАЗВАНИЕ  ОТ     СРОК     РЕЙТИНГ     НАЛИЧИЕ
657  VAG            Болт      317 ₽  сегодня  4.91★ (56)  4 шт
```

Сайт — тяжёлый SPA, который не открывается ни в `curl`, ни в headless-браузере.
API за ним рабочий, просто недокументированный: `/swagger` и `/openapi.json`
отдают 404. Карта из 214 эндпоинтов и способ снять её заново —
[docs/autodoc-api.md](docs/autodoc-api.md).

## Установка

```sh
bun install -g github:pashokitsme/adoc
gh skill install pashokitsme/adoc adoc
```

Вторая команда ставит скилл для агента — после неё Claude Code сам знает, когда
звать `adoc`, и не пытается открыть сайт браузером. Она не обязательна и умеет
не только Claude Code: список агентов — в `gh skill install --help`, обновление
— `gh skill update --all`. Установку можно поручить агенту целиком:

> Установка https://github.com/pashokitsme/adoc через `bun install -g`, затем
> скилл через `gh skill install`. Проверка: `adoc part n90954802` печатает
> таблицу с производителем VAG.

Обновление — `bun remove -g adoc` и установка заново: повторный `bun install -g`
берёт git-пакет из кэша и новый коммит не подхватывает даже с `--force`.
Для работы над самим тулом удобнее клон и `./install.sh` — он линкует checkout,
а не копию.

Зависимость одна: [Bun](https://bun.sh).

## Команды

| | | авторизация |
|---|---|---|
| `search <текст>` | подсказка: категории и производители | |
| `goods <categoryId>` | товары внутри категории | |
| `part <артикул>` | кто выпускает, почём, рейтинг | |
| `info <артикул>` | карточка: гистограмма оценок, наличие | |
| `reviews <артикул>` | отзывы и выжимка нейросети | |
| `prices` · `analogs` | предложения продавцов, аналоги | да |
| `garage` | машины; `parts <id>` — подборка под них | да |
| `basket` · `favorites` · `orders` · `profile` | | да |
| `get <путь> [k=v]` | любой эндпоинт из карты API | `--auth` |

Один артикул бывает у нескольких производителей — тогда `adoc` покажет список и
выйдет с кодом 2; `brandId` передаётся вторым аргументом. `--json` отдаёт сырой
ответ для `jq`. Остальное — `adoc --help`.

## Авторизация

```sh
adoc login      # спросит телефон/email и пароль
```

Пароль читается с терминала без эха, никуда не пишется и аргументом не
принимается — иначе осел бы в истории шелла. Сохраняется только токен:
`~/.config/adoc/token.json`, права 600, обновляется сам. `adoc whoami` — кто
вошёл, `adoc logout` — забыть.

Есть путь без пароля: в консоли браузера на сайте с открытой сессией —
`copy(JSON.stringify(sessionStorage))`, вставка — в `adoc login --paste`.

## Оговорки

API неофициальный: поле могут переименовать, эндпоинт — закрыть. Тул делает те
же запросы, что и сайт, от твоего имени; молотить им чужой сервис — плохая идея.
Токен не покидает локальную машину.
