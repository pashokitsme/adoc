# adoc

Автозапчасти с autodoc.ru из терминала: найти деталь по артикулу или названию,
посмотреть цену, наличие, срок доставки, рейтинг и отзывы, заглянуть в свою
корзину и заказы — не открывая браузер.

```console
$ adoc part n90954802
ID   ПРОИЗВОДИТЕЛЬ  НАЗВАНИЕ  ОТ     СРОК     РЕЙТИНГ     НАЛИЧИЕ
657  VAG            Болт      317 ₽  сегодня  4.91★ (56)  4 шт
```

## Зачем

Сайт autodoc.ru — тяжёлая одностраничная заявка: она не открывается ни в
`curl`, ни в headless-браузере, а на медленной сети и в обычном подтормаживает.
При этом за ней стоит нормальный HTTP API, просто недокументированный:
`/swagger`, `/openapi.json` и `/Help` отдают 404, публичного описания нет.

`adoc` разговаривает с этим API напрямую. Карта из 214 эндпоинтов,
восстановленная из фронтенда и проверенная запросами, лежит в
[docs/autodoc-api.md](docs/autodoc-api.md) — там же записано, как она получена,
чтобы её можно было перевыпустить, когда autodoc что-нибудь поменяет.

## Установка

Нужен [Bun](https://bun.sh).

```sh
git clone <этот-репозиторий> ~/Source/repos/adoc
cd ~/Source/repos/adoc
./install.sh
```

`install.sh` кладёт симлинк `~/.local/bin/adoc` на этот каталог и линкует
скилл в `~/.claude/skills/adoc`. Симлинк, а не копия: правишь файл здесь —
установленный тул меняется сразу. `./install.sh --uninstall` убирает ссылки,
`--no-skill` пропускает скилл, `--dry-run` показывает план.

## Установка через агента

Если у тебя Claude Code или другой агент с доступом к терминалу, отдай ему это:

```
Установи adoc из <адрес-репозитория>: склонируй в ~/Source/repos/adoc,
запусти ./install.sh, убедись что `adoc part n90954802` печатает таблицу
с производителем VAG. Если bun не установлен — поставь его сначала.
```

Вместе с тулом линкуется скилл в `~/.claude/skills/adoc` — после этого агент
сам знает, когда звать `adoc`, и не будет пытаться открыть autodoc.ru
браузером (у него это не получится, сайт не рендерится вне обычного Chrome).

Проверить, что скилл на месте:

```sh
ls ~/.claude/skills/adoc/SKILL.md
```

## Как искать

**Знаешь артикул** — этого достаточно:

```console
$ adoc info n90954802
Болт  n90954802
VAG  id 657

Оценки
  ★★★★★  4.91  56 оценок
  5★ ██████████████████   54
  4★ ··················    1
  3★ ··················    0
  2★ ··················    0
  1★ ··················    1

Наличие и цена
  минимальная цена  317 ₽
  срок              сегодня
  на складе         4 шт
  категория         4558

https://www.autodoc.ru/price/657/n90954802
```

Один и тот же артикул бывает у нескольких производителей — тогда `adoc` покажет
список и попросит уточнить `brandId`, потому что цены и отзывы у них разные.

**Знаешь только название** — сначала подсказка, потом категория:

```console
$ adoc search болт
ID   НАЗВАНИЕ                РАЗДЕЛ
408  Болты                   Инструменты и техника
409  Болты колесные          Автопринадлежности
410  Болты секретки          Автопринадлежности

$ adoc goods 409 --limit 5 --sort 2      # 2 = сначала дешевле
```

## Отзывы

Кроме самих отзывов autodoc показывает выжимку, которую делает нейросеть —
`adoc` выводит её первой:

```console
$ adoc reviews n90954802 --limit 3
отзывов: 35

Выжимка — Нейросеть YandexGPT
  + Как оригинал.
  + Отличное качество.
  + Подходят как родные.
  − Изогнулся при установке.

★★★★★  Юрий Л. · Товар куплен в Автодок
  хороший товар
```

Число оценок и число отзывов не совпадают: оценку можно поставить, ничего не
написав, и в ленту она не попадёт.

## Вход в аккаунт

Без входа доступны поиск, карточка, рейтинг, отзывы и минимальная цена.
Предложения продавцов, аналоги, корзина, избранное, заказы и профиль требуют
авторизации.

```console
$ adoc login

  Вход в autodoc.ru
  пароль вводится без эха и никуда не сохраняется

  телефон или email  ›
  пароль             › ••••••••

  ✓ user5908330
    email    pa•••••@gmail.com
    телефон  +7••••••0874
    город    129
    токен    живёт ещё 60 мин
    refresh  есть
```

Пароль читается прямо с терминала, не отображается, никуда не записывается и
уходит единственным запросом на `login.autodoc.ru`. Передать его аргументом
нельзя намеренно — иначе он осел бы в истории шелла и в выводе `ps`.

Сохраняется только результат: `~/.config/adoc/token.json` с правами `600`.
Дальше токен обновляется сам по refresh-токену. `adoc whoami` показывает, под
кем ты вошёл и сколько живёт токен, `adoc logout` удаляет файл.

Если пароль вводить не хочется, есть путь без него: войди на autodoc.ru в
браузере, выполни в консоли `copy(JSON.stringify(sessionStorage))` и вставь
буфер в `adoc login --paste`.

## Команды

| Команда | Что делает | Нужен вход |
|---|---|---|
| `search <текст>` | Подсказка по названию: категории и производители | |
| `goods <categoryId>` | Товары внутри категории | |
| `part <артикул>` | Кто выпускает артикул, с ценой и рейтингом | |
| `info <артикул> [brandId]` | Карточка: рейтинг, гистограмма, наличие | |
| `reviews <артикул> [brandId]` | Отзывы и выжимка нейросети | |
| `prices <артикул> [brandId]` | Предложения продавцов: цена, срок, количество | да |
| `analogs <артикул> [brandId]` | Аналоги | да |
| `basket` | Корзина | да |
| `favorites [listId]` | Избранное; без аргумента — списки | да |
| `orders` | Заказы | да |
| `profile` | Сводка по аккаунту | да |
| `login` / `logout` / `whoami` | Аккаунт | |
| `get <путь> [k=v ...]` | Произвольный запрос к API | по флагу |

Общие флаги: `--json` (сырой ответ, для `jq`), `--limit`, `--page`,
`--sort`, `--auth` (слать токен в `get`/`post`). Полная справка — `adoc --help`.

## Для скриптов

`--json` отдаёт ответ как есть:

```sh
adoc part n90954802 --json | jq -r '.items[].manufacturer.name'
```

Коды возврата: `0` — нашлось, `1` — ошибка или пустой результат, `2` — артикул
принадлежит нескольким производителям, нужен `brandId`. Цвета гаснут сами вне
терминала и при `NO_COLOR`.

Дотянуться до эндпоинта, под который нет команды, можно напрямую:

```sh
adoc get /api/goods-service/manufacturers/groups
adoc get /api/order-service/orders/count --auth
```

## Что стоит знать

- **API неофициальный.** Никто не обещал его стабильности: autodoc может
  переименовать поле или закрыть эндпоинт без предупреждения. Если что-то
  сломалось, начни с `docs/autodoc-api.md` — там описано, как заново снять
  карту с фронтенда.
- **Это инструмент для личного использования.** Он делает ровно те же запросы,
  что и сайт в браузере, от твоего имени и в твоём темпе. Устраивать из него
  парсер-молотилку — плохая идея и по нагрузке, и по отношению к чужому сервису.
- **Аккаунт твой.** Токен лежит только на твоей машине, никуда не отправляется
  и в репозиторий не попадает.
