# adoc

CLI поверх недокументированного API autodoc.ru. Бинарь — `adoc-autodoc`
(`adoc` пока то же самое), справка `adoc-autodoc --help`, карта 214 эндпоинтов
— `docs/autodoc-api.md` рядом со скиллом.

**Не лезь в autodoc.ru браузером.** Angular-SPA, не поднимается ни
`ofetch`/obscura, ни Playwright: пустой `body`, вид «сайт мёртв». Данные только
через `adoc-autodoc`.

## Что вызывать

| Задача | Команда |
|---|---|
| Есть артикул → кто выпускает, рейтинг | `adoc-autodoc brands <артикул>` |
| Цена, наличие, срок у продавцов | `adoc-autodoc offers <артикул> --brand <имя>` — **нужен вход** |
| То же плюс аналоги | `adoc-autodoc offers <артикул> --brand <имя> --analogs` — **нужен вход** |
| Карточка целиком: рейтинг, гистограмма, наличие | `adoc-autodoc info <артикул> [--brand <имя>]` |
| Отзывы + выжимка нейросети | `adoc-autodoc reviews <артикул> --brand <имя>` |
| Только название детали | `adoc-autodoc search <текст>` |
| Корзина, избранное, заказы, профиль | `adoc-autodoc basket` / `favorites` / `orders` / `profile` — **нужен вход** |
| Машины юзера | `adoc-autodoc garage` — **нужен вход** |
| Что подобрать под его машину | `adoc-autodoc garage parts <carId>` — **нужен вход** |
| Эндпоинт без команды | `adoc-autodoc get <путь> [k=v ...] [--auth]` |

Машине — `--json`: ровно один JSON-объект в stdout, дальше `jq`. Без него
таблица для человека; цвет гаснет сам при пайпе. Ошибка в `--json` приходит
телом `{"error":{"code":"…","message":"…"}}`, без `--json` — текстом в stderr.

Флаг со значением пишется `--flag value` или `--flag=value`: он забирает
следующий токен, поэтому `--page --json` съест `--json` как номер страницы.

## Обязательный порядок: артикул → бренд

Один артикул = много производителей, цена/отзывы/наличие разные. Сначала
`brands <артикул>` — оттуда берёшь `brand`, потом `offers`/`reviews` с
`--brand <имя>`. Имя бренда, не id.

Не угадал бренд или их несколько → выход код **2** и тело
`{"error":{"code":"ambiguous","items":[…]}}` со списком: это не ошибка, а
«уточни». Бери бренд из `items`, повтори.

Коды: `0` — нашлось (пустой список тоже `0`), `2` — уточни бренд, `1` —
всё остальное.

## Гараж

`adoc-autodoc garage` — спрашивай первым, когда юзер говорит «моя машина» без
модели: там марка, модель, модификация, год, VIN. Гадать не надо. `★` =
основная машина. `adoc-autodoc garage parts <id>` даёт подборку autodoc под
модификацию — расходники, цены, сроки. `garage export` — тот же гараж в
контрактном виде для машинной обработки.

VIN и id машин — личные данные. Юзеру показывай, в сторонние запросы не тащи,
не публикуй.

## Ловушки

1. **`search` отдаёт товары первой подходящей категории, а не всё подряд.**
   Остальные найденные категории — в `extra.categories`; по ним ходи
   `adoc-autodoc goods <categoryId>`. Полнотекстового поиска по товарам нет —
   текст в `find-goods` даст `totalCount: 0`, не баг.
2. **Оценки ≠ отзывы.** `info` даёт `4.91★ (56)`, `reviews` — «отзывов: 35».
   Оценка без текста в ленту не идёт. Не смешивай.
3. **`{"error":{"code":"auth"}}` в `--json` или текст про вход в stderr =
   нужен `adoc-autodoc login`.** Тело ответа сайта при этом пустое, смотри код
   ошибки, а не HTTP-тело. `describe` помечает `offers` как `auth: false`, но
   предложения без токена всё равно отдают `auth` — верь коду ошибки.
4. **Регистр параметров важен** в `adoc-autodoc get`: почти везде PascalCase
   (`Article`, `ManufacturerId`, `PageNumber`), но поиск по артикулу —
   `article` со строчной. Сверяйся с `docs/autodoc-api.md`, не с интуицией.
5. **Артикул регистронезависим** — `n90954802` = `N90954802`, пробелы и дефисы
   тоже не важны.

## Авторизация — дело пользователя

Вход = пароль, вводит только человек: `adoc-autodoc login` читает с терминала
без эха. **Никогда не проси пароль в переписке и не суй в команду** —
аргументом не принимается нарочно, чтоб не осел в истории шелла и в `ps`.

Нужен вход, аккаунта нет → скажи юзеру запустить `adoc-autodoc login` самому,
жди. Проверка безопасна: `adoc-autodoc whoami` печатает `ok` и имя. `ok:true` —
аккаунт есть и токен годен; `ok:false` — входа нет или токен протух, лечится
тем же `login`. Email и телефон он показывает **как есть, без маскировки** —
это личные данные юзера: показал ему и забыл, наружу не отправляй.

Файл аккаунта — `~/.config/adoc/accounts/autodoc.json`, права 600, обновляется
сам. **Не читай его и не печатай**: там токены. По той же причине не запускай
`login --json` — он печатает токены в stdout.

## Когда API молчит

404 или поле пропало → autodoc поменял фронт. В `docs/autodoc-api.md` есть
воспроизводимый способ снять карту заново: качай чанки Angular-бандла, грепай
пути, методы, имена параметров. Надёжнее, чем гадать URL-ы.
